# Embedded Chinese font

`AR-PL-KaitiM-Big5.woff2` is a WOFF2 conversion of **AR PL KaitiM Big5
2.10**, published by Arphic Technology under the ARPHIC PUBLIC LICENSE.

The original font package is available as
[`@fontpkg/ar-pl-kaiti-m-big5`](https://www.npmjs.com/package/@fontpkg/ar-pl-kaiti-m-big5).
The license text and copyright metadata remain embedded in the converted font.
