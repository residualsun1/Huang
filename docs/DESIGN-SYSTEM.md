# Warm Geist 设计系统

Warm Geist 是本站对 Vercel Geist 规范的本地化应用。它保留原站的暖纸背景与复古气质，
使用 Geist 的信息层级、间距、圆角、边框和交互方法组织界面。它不是 Vercel 品牌的复制。

## 基本原则

- 内容优先，高对比度，大量但有节奏的留白。
- 使用背景与边框建立层级，阴影只用于轻微抬升。
- 棕色只表示链接、焦点、状态和少量品牌信息，不作为装饰铺色。
- 动效只解释状态变化，通常为 150ms，并遵循 `prefers-reduced-motion`。
- 中文正文比英文 Geist Copy 使用更宽松的行高。

## 核心 Token

| 角色 | 值 |
| --- | --- |
| 页面背景 | `#f3f1ed` |
| 抬升表面 | `rgba(250, 248, 244, 0.76)` |
| 主要文字 | `#1d1b1b` |
| 次要文字 | `#56534f` |
| 弱化文字 | `#8a8680` |
| 默认边框 | `rgba(29, 27, 27, 0.12)` |
| 品牌与焦点 | `#8b4513` |
| 代码块背景 | `#efebe4` |

间距使用 4px 基础刻度：`4、8、12、16、24、32、40、64、96px`。
常规圆角为 6px，浮层为 12px，大型表面为 16px，胶囊只用于状态和标签。

## 字体

- Huang 字标与简介中的拉丁字符：Newsreader，形成接近古典出版物的高对比衬线气质。
- 中文简介、首页栏目大标题与文章正文：思源宋体体系，作为暖纸背景上的主要编辑性表达。
- 导航、卡片和正文：Geist Sans，后接中文系统无衬线字体。
- 日期、编号和标签：Geist Mono；代码块使用 Geist Mono 与思源黑体/系统中文无衬线字体组成的专用回退栈。
- 首页文章标题的拉丁字符：Libre Baskerville，中文回退到思源宋体体系。
- 文章正文：思源宋体（网页端使用同源的 Noto Serif SC，并回退到本机 Source Han Serif SC）。
- 正文引用：系统楷体，依次回退至 Kaiti SC、STKaiti 与 KaiTi。

Geist 字体目前锁定到 `1.7.2`，Newsreader 使用 Fontsource 可变字体；二者通过 jsDelivr 加载。字体不可用时自动使用系统字体，
不会影响内容阅读。若未来需要完全离线部署，可将相同版本字体移入 `public/fonts/`。

## 页面结构

- 全局内容宽度：1040px，使视线集中于中央内容带。
- 首页：导航、紧凑的纯文字自我介绍、X 与 GitHub 社交入口、三列项目卡片，以及提示词、写作、阅读的统一列表。栏目顺序为“01 / 项目、02 / 提示词、03 / 写作、04 / 阅读”；提示词展示最新三篇，写作与阅读各展示最新五篇并提供归档入口。栏目标题右侧保留延伸分隔线，文章行之间只用留白分组，不重复绘制横线；文章标题使用 Libre Baskerville/思源宋体回退、400 字重和棕色文字，悬浮时显示同色下划线。首页不加载像素场景和动画脚本，以内容为第一视觉重心。
- 首页简介：最大 720px 行宽，思源宋体 14px；首句提升为 15px 和更深文字色，其余段落保持较弱对比度。
- 写作文章：与首页共享 `#f3f1ed` 暖纸背景；标题下不显示 description 摘要，作者和发布日期在左，标签在右。正文最大 740px，使用思源宋体和克制的段落留白；引用使用无底色楷体书摘样式。961px 以上显示 220px 粘性目录，底部按同栏目发布日期自动生成轻量的上一篇与下一篇导航。
- 代码块：使用一体化圆角容器，上方暖灰工具栏显示文件名或代码类型且只保留“复制”，下方使用更轻的 `#efebe4` 暖灰背景、中文无衬线字体和低饱和语法色。外壳带两层极轻环境阴影，只用于从纸面背景中建立层次；较长代码可在块内横向滚动，超长代码可纵向滚动。常驻界面不提供语言切换和“原始 / 渲染”。
- 项目与提示词详情：保留 Warm Geist 的现代技术文档样式，不继承写作页的纸张排版。
- 页眉与页脚：不使用横向边线；页脚左侧以 Times New Roman 显示联系邮箱，右侧保留年份信息。
- 移动端：32px 页面总侧边距，隐藏目录，列表和 Hero 自动变为单列。

样式以 `public/styles.css` 为唯一视觉来源；页面结构由 `scripts/build.mjs` 生成。
Markdown 内容与 Hugo 兼容层不承担页面视觉职责。
