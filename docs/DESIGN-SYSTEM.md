# Warm Geist 设计系统

Warm Geist 是本站对 Vercel Geist 规范的本地化应用。它保留原站的暖纸背景与复古气质，
使用 Geist 的信息层级、间距、圆角、边框和交互方法组织界面。它不是 Vercel 品牌的复制。

## 基本原则

- 内容优先，高对比度，大量但有节奏的留白。
- 使用背景与边框建立层级，阴影只用于轻微抬升。
- 棕色只表示链接、焦点、状态和少量品牌信息，不作为装饰铺色。
- 动效只解释状态变化，通常为 150ms，并遵循 `prefers-reduced-motion`。
- 中文正文比拉丁文字使用更宽松的行高。

## 核心 Token

| 角色 | 值 |
| --- | --- |
| 页面背景 | `#f2ede3` |
| 抬升表面 | `rgba(250, 247, 241, 0.8)` |
| 主要文字 | `#1d1b1b` |
| 次要文字 | `#56534f` |
| 弱化文字 | `#8a8680` |
| 默认边框 | `rgba(29, 27, 27, 0.12)` |
| 品牌与焦点 | `#8b4513` |
| 代码块背景 | `#efebe4` |

间距使用 4px 基础刻度：`4、8、12、16、24、32、40、64、96px`。
常规圆角为 6px，浮层为 12px，大型表面为 16px，胶囊只用于状态和标签。

## 字体

- 全站普通拉丁字符：Libre Baskerville，中文按所在区域回退至思源宋体、楷体或系统字体。
- 中文简介、首页栏目标题与文章正文：思源宋体体系，作为暖纸背景上的主要编辑性表达。
- 代码、文件名与键盘按键：Geist Mono 与思源黑体/系统中文无衬线字体组成的专用回退栈。
- 文章正文：思源宋体（网页端使用同源的 Noto Serif SC，并回退到本机 Source Han Serif SC）。
- 正文引用：拉丁字符使用 Times New Roman，中文使用按需加载的 LXGW WenKai，并保留 Kaiti SC、STKaiti 与 KaiTi 作为系统回退，保证移动端也能稳定呈现楷体气质。

Libre Baskerville 与 Noto Serif SC 通过 Google Fonts 加载，代码字体 Geist Mono 锁定到 `1.7.2` 并通过 jsDelivr 加载。字体不可用时自动使用系统字体，
不会影响内容阅读。若未来需要完全离线部署，可将相同版本字体移入 `public/fonts/`。

## 页面结构

- 文章与归档页面保留 1040px 最大框架；首页单独使用 880px 中等宽度。它比初版更聚焦，同时把上一版右侧目录所占空间归还给正文与照片，避免 700px 内容列带来的局促感。
- 首页：页眉只保留 Huang 字标，不显示水平栏目导航或右侧目录；页眉与正文共同引用 `--paper-surface`，呈现相同的均匀纸粒和极淡斜纹，不使用真实模糊滤镜。主体包含占满内容宽度的纯文字自我介绍、X 与 GitHub 社交入口、三行编辑式项目列表，以及 Prompt、写作、阅读的统一列表。首页不再加载或预留个人照片空间，自我介绍缩短后的高度会让下方栏目自然上移。栏目顺序为“01 / 项目、02 / Prompt、03 / 写作、04 / 阅读”，每个栏目最多展示最新三项。项目列表不使用独立卡片底色和厚阴影；每行由统一图标画布、项目名称与一句简介、右侧仓库与项目地址组成，并以极淡分隔线和 Hover 暖色提示交互。文章列表采用日期在左、标题与摘要在右、箭头收尾的顺序。栏目标题右侧保留延伸分隔线；文章行之间只用留白分组。首页不加载像素场景和动画脚本，以内容为第一视觉重心。
- 全站背景：以 `--background-100` 的暖灰底色为基础，通过共用变量 `--paper-surface` 叠加两层低透明度微粒和一层 `8px` 的极淡斜向纹理，形成克制的纸张感；正文和页眉都不使用 `backdrop-filter` 模糊。
- 首页简介：最大 720px 行宽，思源宋体 14px；首句提升为 15px 和更深文字色，其余段落保持较弱对比度。
- 项目、写作、Prompt 与阅读正文：共享 `#f2ede3` 暖纸背景和同一套编辑性阅读排版；详情标题区不显示栏目归属小标题，也不显示 description 摘要，作者和发布日期在左，标签在右。正文最大 740px，使用思源宋体和克制的段落留白；引用使用无底色楷体书摘样式。961px 以上显示 220px 粘性目录，页面滚动进入新章节时，目录对应链接通过 `aria-current="location"` 自动切换为 Hover 的深色，并在长目录中自动保持可见。四个栏目的上一篇与下一篇均使用正文列内的两列卡片，且不显示上方分隔线；卡片复用页面暖纸底色和完整纸张纹理。
- 拉丁文字：除代码、文件名和键盘按键等技术内容外，全站统一优先使用 Libre Baskerville；中文继续按各区域回退至思源宋体或楷体。
- 代码块：使用一体化圆角容器，上方暖灰工具栏显示文件名或代码类型且只保留“复制”，下方使用更轻的 `#efebe4` 暖灰背景、中文无衬线字体和低饱和语法色。外壳带两层极轻环境阴影，只用于从纸面背景中建立层次；较长代码可在块内横向滚动，超长代码可纵向滚动。常驻界面不提供语言切换和“原始 / 渲染”。
- 页眉与页脚：不使用横向边线；页脚邮箱与年份中的拉丁文字统一使用 Libre Baskerville。
- 移动端：页面使用 32px 总侧边距，简介保持单列，文章列表使用紧凑的日期、标题与箭头三列布局。项目区继续保持一行一个项目，图标缩小为 56px，仓库与项目地址在简介右侧上下排列，避免留下无意义的横向空白。

样式以 `public/styles.css` 为唯一视觉来源；页面结构由 `scripts/build.mjs` 生成。
Markdown 内容与 Hugo 兼容层不承担页面视觉职责。
